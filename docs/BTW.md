# git-zen 零散想法的实现

> 一些未归类的想法和实现，后续可以考虑整理到其他文档中。

## 设置功能

### 外观（设置入口：右上角齿轮）

- [x] 主题：跟随系统 / 浅色 / 深色 + Catppuccin Latte·Mocha、One Dark、GitHub Light·Dark，共 8 种；`data-theme` CSS 变量切换，即时生效
- [x] 字体：UI 字体输入框 + 字号滑条（11-17px），即时生效并持久化
- [x] diff 样式：新增/删除的背景色+文字色四个取色器，独立于主题配置，即时生效

### 个性化

- [x] 创建分支的前缀：设置后新建分支自动补前缀（已含前缀则不重复加），输入框 placeholder 提示

所有设置存 localStorage，启动时在挂载前应用避免闪默认样式。

## UI 优化

- [x] 分支区折叠树：本地/远程分组，远程按前缀合并（origin/xxx 归入 origin 组），组头点击折叠/展开，显示数量；远程子项只显示短名
- [x] 分支前缀树：本地分支也按 `/` 前缀自动递归合并（feat/x、feat/y 归入 feat），任意层级可展开收起，节点显示后代数量；实现抽为 `branchTree.ts` + 自递归 `BranchTree.vue`，本地/远程共用
- [x] hover 的 tooltip 美化：新增 `ui/Tooltip.vue` 组件（跟随鼠标、多行支持、Teleport 到 body 防裁剪、右半屏自动左翻），分支树/历史行/文件行已全部换用

## UX 优化

- [x] 切换分支先乐观更新选中态（侧栏高亮 + 状态栏分支名立即变），历史区盖 loading 遮罩，完成后刷新真实状态；失败自动回滚
