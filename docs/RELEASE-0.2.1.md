# git-zen 0.2.1

上一版 `0.2.0` 之后共 **4 个提交**，一条主线：**把文件列表从「一行一个完整路径」变成有层级的目录树**，
并让它同时服务变更列表与 diff 弹窗。附带两个真缺陷修复。

## 变更列表：目录树（可切换）

- **目录树**。此前一个中等规模的改动，路径前缀几乎把列表撑满 —— 横向空间全花在重复的
  `src/components/` 上，真正要读的文件名被挤到右边。现在按 `/` 折成层级。
- 目录可折叠（收起时报「里面还有几个」）、有过滤框（**搜索时自动展开命中路径上的目录**，
  否则会出现「搜到了但看不见」）、目录行上能直接暂存 / 取消暂存整棵子树。
- **两种视图可切换**，偏好存在设置里、跨重启保留。默认**平铺**：树是可选增强，
  默认保持大家熟悉的样子。
- 目录行的折叠键用所选区的完整路径，「已暂存」与「未暂存」两个区的折叠状态互不干扰。

## diff 弹窗：左侧文件列表同样可切换

- `DiffViewer` 左侧的文件列表也支持目录树 / 平铺，偏好与变更列表**共用** ——
  「我喜欢怎么看文件列表」是一件事，不该在两个地方各问一次。只有一个文件时按钮不出现
  （没有层级可省）。
- 做法是**把既有实现变成泛型，而不是复制一份**：`src/lib/fileTree.ts` 的
  `buildFileRows(files, opts)` 改成 `buildFileRows(items, pathOf, opts)`，元素类型由调用方说明，
  层级 / 压平 / 折叠 / 过滤一份不改，于是同一套逻辑同时服务变更列表的 `StatusFile[]`
  与 diff 弹窗的 `PatchSection[]`。
- 一个容易丢的细节：变更列表的过滤一直匹配 porcelain 的原始串（重命名是 `old -> new`，
  **用旧名也能搜到**），而树里落位只能认新名。泛型化时若图省事只留一个 `pathOf`，
  这条既有行为就悄悄没了，因此额外留了 `matchOf`，并各配一条用例钉住。

## 修复

- **删除 stash 记录后，暂存架列表不更新**。这不只是显示旧数据：`stash@{n}` 里的 n 是**位置**
  不是身份，删掉一条之后其余记录整体前移，旧列表上的「恢复」会落到**另一条记录**上。
  根因是暂存架列表为「打开菜单时才拉」的懒加载，不在统一重拉的 status/log/branches 里，
  而菜单项有意不关（方便连续删），于是旧列表一直留在屏幕上。现在删除成功后通知面板重取。
- **两个计数徽标从未生效**。`<Badge>` 在模板里用了两次，`<script setup>` 里**从来没有 import 它** ——
  Vue 对没解析出来的标签不报错，直接当普通元素渲染，`variant` 整个属性被忽略，
  两个计数一直只是没有任何样式的纯文本。`vue-tsc` 与 `vite build` 都不报，
  唯一症状是「少了一层颜色」。改目录树时顺手发现。

## 工程防护

`pnpm verify` = 契约检查 + 对比度检查 + 类型检查 + **8 个前端自检** + 构建。
本次新增 `src/lib/fileTree.test.ts` 的泛型用例（换一种元素类型必须能直接用）。
