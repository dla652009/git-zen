# git-zen 0.5.1

小版本，**外观设置重做**：主题从 6 个平铺选项改成「模式 × 配色方案」两维，
并且改成点击即时预览。

## 外观：先定深浅，再挑风格

原来的主题列表是混排的：浅色、深色、Catppuccin×2、Windows 7、Windows XP 挤在一起。
要挑「那个深色的」，得先认全 6 个名字。

现在分成两步：

- **模式**：浅色 / 深色 / 跟随系统
- **配色方案**：按模式过滤。每张卡片画出 6 个核心色块
  （画布 / 卡片 / 主色 / 前景 / 成功 / 修改），看颜色就能判断风格

深色模式下只列深色方案，浅色模式下只列浅色方案。

## 点击即预览，取消则还原

主题、字体、字号一改就立刻生效，不用先点保存再看效果。

点「保存」才写入配置；点「取消」/ X / 点遮罩 / 按 Esc 会**全部还原**成打开前的样子。

（预览只改界面，不碰配置文件 —— 之前直接改配置的话，点错一次就存进去了，取消也回不去。）

## 升级说明

旧的主题配置会自动迁移，不需要手动改。比如原来选的 Windows XP，升级后是
「浅色模式 + Windows XP」。

这一版通过自动更新推送。如果你在 0.5.0 或更高版本，会收到提示；
0.4.0 及更早的版本还没有 updater 代码，需要手动装一次。

## 安装

```
git-zen_0.5.1_x64-setup.exe   约 4.3 MB
```

安装包未签名，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。

依赖系统 WebView2 运行时（Win11 自带；Win10 一般已随 Edge 安装）。
