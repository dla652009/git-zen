## 独立复核发现与修复

首次有源码证据的独立审查确认三项问题，修复后重新验证：

1. 历史行整行背景绘制在 SVG 上方，Win7/XP 不透明选中色会遮掉泳道。改为独立背景层从泳道右侧开始绘制，保留整行鼠标命中；泳道始终压在原主题画布上，原图形对比度检查仍适用。
2. 选中重命名行时旧名称仍用 muted，light 约 4.21:1。已暂存 / 未暂存两处均按选中状态改为前景色，保留删除线表达旧名称。
3. 元数据固定 12rem 不收缩，挤占窄栏主题。新增 35% 上限与收缩能力，历史区宽度不超过 40rem 时收起 hash，保留完整原生 title；不改变栏宽、行高或虚拟滚动。旧 WebView 忽略容器查询时仍有宽度上限兜底。

原静态检查未覆盖绘制顺序和嵌套 muted 文案；对应的人工最小复现步骤与原因已写入 NOTES.md。静态对比度检查额外覆盖浮层基底，不能替代运行时绘制审查。
