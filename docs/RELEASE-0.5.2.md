# git-zen 0.5.2

安装体验修正，外加一个会让分支树看起来"坏掉"的坑。

## 安装包说中文了

之前的安装界面是英文的：语言没配置，走的是 Tauri 默认值（只有 English）。

现在全程中文——"下一步"、"安装"、"已经安装了，选择你想要执行的操作后点击下一步以继续"，
卸载程序也是中文。安装器窗口左上角显示应用图标。

不弹语言选择框，装上就是中文。

## 分支树出现奇怪嵌套时

如果分支树里冒出这么一层：

```
HEAD (detached at refs 1)
  └─ heads 1
       └─ feature 1
            └─ 0.1
```

而你的分支本该叫 `feature/0.1`——这说明 HEAD 脱离了分支（游离状态）。

成因是两条叠加：完整引用名（`refs/heads/xxx`）被当成分支名传给了检出命令，
以及仓库里存在与分支同名的 tag。

这一版加了两道防线：

- 检出命令拒绝 `refs/` 开头的名字，并提示改用短名。这类输入只可能来自脚本或手滑粘贴
- 发布流程不再支持手动触发。之前手动触发会拿分支名当 tag 名，凭空造出与分支同名的
  tag，正是上面那条歧义的来源

## 更新弹窗里的说明

0.5.1 的弹窗显示"本次更新没有附说明"，是因为发布流程里正文被写死成空字符串。
现在会从版本对应的发布说明读取，并剥掉 markdown 标记——弹窗是纯文本展示的，
不该出现一堆井号和星号。

## 安装

本版之后自动更新会带上说明。

安装包未签名，Windows SmartScreen 可能提示"未知发布者"，选择"仍要运行"即可。
依赖系统 WebView2 运行时（Win11 自带；Win10 一般已随 Edge 安装）。
