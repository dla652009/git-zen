# git-zen 0.4.0

上一版 `0.3.0` 之后共 **30 个提交**（11 个功能、9 个修复、8 个重构、2 个样式），
主线是**工作流变成可流通的资产**、**仓库总览升级为多仓库控制台**，
以及一批「点了没反应 / 界面乱跳」的交互顽症。

## 工作流：从本机配置到可流转的资产

- **配置可导入导出**。每条工作流右侧有「导出为文件」，区块头部有「导入…」与「导出全部」。
  格式是带 `kind` / `version` 的 JSON，缩进 2 格，人能直接读改。
  导入接受三种形状（完整导出文档 / 裸数组 / 单个工作流对象），手写一个也能喂进去；
  导入时重新生成 id、重名加后缀而非覆盖，坏条目跳过并计数。
  于是「给同事一套发版流程」变成发一个文件。
- **新建分支支持写死名字**。填了固定名，运行时不再弹输入框，确认框里少一个空框；
  留空仍是运行时输入。
- **删除分支不存在时直接跳过**，不再是配置项。清理类步骤是「有就删」的语义：
  第一次跑已经删掉了，重跑或换个仓库时不该卡住整条流程。步骤描述里会写明这一点。
  （例外：远程删除填了 `origin/xxx` 且不存在时仍报错——那是名字写错，静默跳过会让人
  以为删成功了。）
- **AI 生成提交信息失效时改用手填**。此前 AI 一失败整步中止，连前面已经生效的
  checkout / merge 都白跑。现在分两种：压根不可用（开关关着 / 没配 Key）就直接问；
  调用失败（网络断、配额耗尽）则文件已暂存好，问一句继续。
  取消 = 步骤失败可重试，不静默跳过（跳过会导致 push 推旧状态）。

## 仓库总览：多仓库控制台

- **支持按分组展示**，顺序与标签栏完全一致，未分组放最后，可折叠。
  每组头部带「N 变更 / N 落后」汇总，折叠着也能看出哪组有活要干。
- **一键切换分组 / 平铺**，状态跨重启保留。
- **按组勾选**：组头三态勾选框（全选 / 部分 / 未选），一点整组选中或取消。
  勾选后可对这批仓库统一「全部拉取」或跑工作流。

## 分支与提交列表

- **远程分支改为双击检出**。此前单击就直接 checkout——手滑一下当前分支就没了。
  现在单击不动作、双击才检出到本地，右键菜单第一项也加了同款入口。
  本地分支保持单击切换（最高频操作）。
- **提交行三段定优先级**。长远程分支名会把提交主题挤成几像素宽甚至完全看不见。
  现在主题保底、refs 限宽 45% 且可收缩、作者列固定窄列。
  远程分支徽标去掉 `origin/` 前缀（蓝色已表示远程），最多显示 2 枚、其余折成 `+N`，
  日期 `5 days ago` 压缩成 `5d`。实测 420px 行宽下主题从 93px 涨到 139px。
- **工作树身份标识**（只读）。标签栏区分主工作树与从属工作树，顶栏同步显示。

## 交互顽症的修复

这一批都是「不会报错，但用起来别扭」的问题：

- **新建 MR 挪到分支右键**。源分支 = 当前分支，目标 = 被右键的那个，两边都由点击
  明确指定。随之删掉三层配置面（状态栏 MR 项、多条预设、URL 模板）——
  它们都是为了「入口在状态栏、目标分支得猜」而存在的。
- **冲突提示横幅被 flex 压成空条**。右栏是 flex 列，列表区 `flex-1` 的 basis 为 0，
  溢出时负压缩全落在没有 `shrink-0` 的固定行上：横幅被压到 13px，`overflow-hidden`
  再裁掉文字，看起来就是一条淡蓝色空条（暂存文件越多越扁）。
- **冲突横幅文字折成三行**。右栏本来就窄，图标 + 标题 + 括号说明 + 副文案 + 按钮全挤
  一行。改为纵向三段：标题行 / 一行小字 / 操作单独一行右对齐。
- **切换仓库偶尔「点了没反应」**。根因是历史区加载遮罩的竞态：被序号作废的那次
  activate 不会执行 finally，遮罩永久残留、盖住整个历史区。
- **下拉面板被裁剪 / 一滚动就自己关掉**。面板改 Teleport 到 body + fixed 定位，
  按视口翻转；内部滚动不再误判为「页面滚动」而关掉自己。
- **展开 ⋯ 菜单时界面跳动**。ContextMenu 曾是 `space-y-2` 的子元素，
  那个兄弟选择器会给 `position:fixed` 的元素也加 8px margin。改用 Teleport。
- **底栏高度跳动 / 远程按钮突然出现**。固定 `h-8`，远程按钮与变更计数改为 170ms 淡入，
  不再撑高整条状态栏。
- **Windows 保留名文件卡住整批暂存**。`CON` / `PRN` / `AUX` / `NUL` / `COM1-9` /
  `LPT1-9` 在 Win32 层被重定向到设备，git 读它必然 ENOENT。现在报错改成中文可执行
  建议（改名或删除），并且「全部暂存」改为逐个 add——一个坏文件不再拖垮整批。

## 分组与设置

- **分组管理重做为双栏**：左栏分组列表（CRUD + 拖排序），右栏当前分组的成员与
  可加入候选，支持勾选批量加入。搜索框语义收敛到右栏两个列表，
  从文件夹右键进入时直接选中该分组。
