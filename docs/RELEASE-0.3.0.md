# git-zen 0.3.0

上一版 `0.2.1` 之后共 **52 个提交**（21 个功能、14 个修复），是迄今最大的一次更新。
四条主线：**MR / PR 全家桶、命令面板、视觉与手感大修、仓库管理补全**。

## MR / PR：从查看到创建的完整链路

- **一键直达新建 MR 页**。状态栏「远程」按钮右键 →「新建 MR」，GitHub / GitLab
  （含自建与多级 group）/ Gitee / Bitbucket 自动推断新建页 URL，分支名按平台规则编码。
  识别不了的主机可在设置里用 `{src} {dst} {repo}` 模板兜底（Gerrit、Gitea 等也能接）。
- **多条 MR 预设**。设置 › 远程 里配「源分支（留空 = 当前分支）+ 目标分支」，一个仓库
  配多条（→ dev、→ release/dev…），右键菜单里每条一个入口。预设按仓库存，互不串扰。
- **AI 生成标题与描述**（设置 › AI 可开关，默认关）。基于「当前分支相对目标分支的
  merge-base diff」——三点口径，和 MR 页面展示的内容完全一致——生成标题与 2-5 条
  要点正文，风格跟随仓库近期提交。生成后先进**预览框**：可编辑、可重新生成，
  确认后再带参跳转。Bitbucket 等不支持 URL 预填的平台自动退化为「复制并打开」，
  标题描述进剪贴板。

## Ctrl+K 命令面板

仓库、分支、动作三类混排搜索。空查询显示最近 5 个仓库 + 常用动作；输入即过滤，
↑↓ 选择（自动跳过禁用项）、Enter 执行。原有 Ctrl+P（切仓库）/ Ctrl+B（切分支）不变，
并存。

## 视觉与手感

- **Windows XP (Luna) 主题**。米银画布、3D 起伏控件、方角与虚点焦点框；主题列表
  现为 6 套（深/浅/Catppuccin×2/Win7/XP）。
- **弹窗退场动画**。此前所有弹窗、右键菜单、下拉「开是软的、关是硬的」——现在关闭
  同样有 170ms 淡出 + 面板轻缩。
- **切换仓库的方向性动画**。分支侧栏、历史区、变更面板按切换方向 ±16px 滑入，
  0/30/60ms 错峰；数据分批到达不会打断动画。
- **暂存/取消暂存的 FLIP 动画**。文件在两个列表间移动时有连贯的淡入淡出与重排滑动，
  目录树/平铺两种视图都生效。
- **分支树折叠高度动画**，连续点击可中途折返。
- **Tooltip 延迟 400ms**，工具栏快速扫过时零延迟切换，不再闪成一片。
- **数字统一等宽排版**，徽标、统计、行号不再抖动。
- **刷新不再盖全屏遮罩**，反馈收敛到刷新按钮本体。
- **自绘标题栏**：窗口镶边消失，标题栏由应用自己画（Win7 主题下是 Aero caption）。
- 文案全面梳理：术语统一（标签栏）、tooltip 去冗余、交互措辞对齐。

## 仓库管理与工作流（0.2.1 之后陆续落地）

- **多仓库工作流**：把「切分支 → 拉取 → 合并 → 推送」流程批量作用于勾选的仓库，
  失败可单独补跑；工作流新增删除分支 / 删除远程分支步骤。
- **重置到干净状态**：一键丢弃当前分支全部改动（刻意不动 .gitignore 忽略的文件），
  并放弃进行中的合并/拣选/变基。
- **时间线（reflog）**：找回被覆盖的提交，一键回到任意一步。
- **冲突「下一步」引导**：未解决/已解决状态与完成合并出口，不再只能放弃合并。
- **全部仓库总览**：一屏看完谁落后、谁有未提交改动，全部拉取、批量跑工作流。
- **推送前预览**：先列出这次要推哪些提交与增删行数（可关）。
- **提交后推送**、amend / 撤销上次提交收进「⋯」菜单。

## 修复（节选）

- 重置功能与全局忽略规则的三处交互缺陷（深层 `!` 放行、通配文件名、只暂存的
  .gitignore）
- 多仓库批次执行器的收口问题与游离 HEAD 场景
- 提示条（toast）宽度/高度/折叠的系列修复，最终形态：顶部居中、图标可辨、
  多条叠摞展开可读
- AI 报错不再挂在提交框；带端口的远程地址放行；AI 请求错误带真实原因
