# git-zen 0.2.0

上一版安装包构建于 2026-09-08（`0.1.0`），其后共 **69 个提交**。这一版主要是三件事：
把 git 调用的安全边界补上、把视觉尺度从「就地决定」改成「分档」、把 `App.vue` 拆开。

## 后端：git 调用不再能被参数带着走

- **选项注入**。`git checkout` / `git push -u` / `git tag push` 的位置参数能被 `-` 开头的名字劫持 ——
  实测 `git update-ref refs/heads/-f HEAD` 之后 `checkout -f` 会**静默丢弃工作区改动**；
  push 的回落分支能被塞进 `--mirror`，把全部本地分支推上远程。现在位置参数统一隔离
  （`--end-of-options` / `--`）加白名单校验。注意 push 场景 `--` 不起作用，只有 `--end-of-options` 挡得住。
- **路径越界**。`check_repo_path` 现在遍历**全部**路径分量 —— 第一版只查首段，`a/../../x` 从缝里漏过
  （Windows 下 `/x` 的 `is_absolute()` 还是 false，但 `join` 照样能逃出仓库）。
- **超时**。所有 git 子进程都有上限（本地 120s / 网络 600s）。这里踩到并修掉一个真缺陷：
  kill 掉 git 之后，孙进程（`git-remote-https` / `ssh` / 凭据助手）仍攥着管道句柄，
  `join()` 会一直阻塞（实测仍等满 29 秒），超时形同虚设。改成边读边发 + 限时收集。
- **失败信息**。`run()` 失败时 stderr 为空会回落读 stdout。此前「提交无内容」与「merge 冲突」
  这两条最高频的失败路径弹的是**完全空白的错误框**。
- 新增 `git_push_force`（只走 `--force-with-lease`，严禁裸 `--force`）、`git_merge_abort`、
  `git_init`、`git_discard_staged`。

## 视觉系统：从「就地决定」到分档

- **四层表面**（画布 / 内嵌区 / 面板 / 浮层）。此前弹窗底色与它下面的侧栏面板一模一样，
  只能靠阴影硬撑，而 24 个弹窗共用同一个 `shadow-xl`，等于没有层次。
  **层次只往上加一层，各主题原有配色一个字节没动。**
- **尺度分档**：字号从 8 档任意值（111 处）收敛到 6 档全 rem（跟随字号设置）；
  圆角 4 档、阴影 4 档、动效时长 3 档、弹窗宽度 4 档。
  此前的根因是「每个值都在用到它的那一刻就地决定，没有一个地方规定过一共几档」。
- **对比度自动校验**：`scripts/check-contrast.mjs`，7 套主题共 266 项
  （文字与徽标 ≥4.5、危险按钮 ≥4.5、语义色、图形 ≥3）。改配色后必跑。

## 交互：逐条来自实机反馈

- **diff 阅读**：Diff 面板加全屏按钮；diff 内搜索（共用引擎；`Enter` / `Shift+Enter` 跳命中，
  显示「当前 / 总数」）；文件变更历史补齐全屏与搜索。
- **分组管理**：补上「拖得进、拖不出」—— 成员可拖出、可一键移出，文件夹加右键菜单
  （重命名 / 管理 / 删除），管理弹窗内可把成员拖到另一个组，归组 / 移出 / 删组都有提示，
  文件夹上显示成员数，超长分组名截断。
- **工作流**：步骤与列表拖拽排序、按步骤独立输入槽、新建分支的前缀改成运行时下拉
  （候选取「个性化 → 分支前缀」）、钉住常用流程、复制工作流 / 复制步骤、失败可从失败处重试。
- **丢弃暂存区全部改动**（新增）。三条候选路径里只有一条能用：
  `git restore --staged --worktree` 在空仓库报 `could not resolve HEAD`，
  `reset --hard HEAD -- <paths>` 直接 fatal，最终走 `ls-tree` 分区 + `checkout HEAD` / `rm`；
  重命名文件必须同时传旧名和新名。
- 顶栏控件语法统一（有文字标签的实心带框、纯图标扁平退色）；分支树加层级引导线并统一行高；
  提示从右下角移到屏幕底部居中（原来压在「提交」按钮上）；徽标从实心药丸改成柔和标签；
  合并冲突时提示并刷新界面；操作进行期间点仓库选项卡不再无响应；设置页快捷键清单与实现对齐。
- **窗口标题改为「Git Zen」**。exe / 安装包 / 开始菜单仍是 `git-zen`（见下方安装说明）。

## 架构：App.vue 拆分

`src/App.vue` **3494 → 2707 行**：抽出 6 个 composable
（`useAiPanel` / `useRepoCache` / `useRepoSession` / `useSidebarResize` / `useSwitcher` / `useWorkflowRun`）
与 13 个弹层组件。行为等价；模板结构由构建兜底 ——
`vue-tsc` **不检查模板结构**（漏了结束标签它仍 exit 0，只有 `vite build` 会报），已实测确认，
`pnpm verify` 因此补上了构建这一段。

## 工程防护

- `scripts/check-contract.mjs`：49 个 command 全部注册 + `gitApi.ts` 与 `git.rs` 的 9 个 serde struct
  字段一致（把 AGENTS.md 硬性规则 1 与 3 变成自动检查，第一条历史上栽过三次）。
- 7 个前端自检 + 21 个 Rust 单测。
- `pnpm verify` = 契约 + 对比度 + 类型检查 + 7 个自检 + 构建，一条命令。

- diff 折行开关（回到永远折行）。

  改了等于清空用户的设置、字号、主题与仓库列表。所以**从 0.1.0 升级会原地覆盖，设置保留**。
