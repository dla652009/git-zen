# git-zen 0.5.0

上一版 `0.4.0` 之后共 **5 个提交，全部是功能**。主线两条：
**应用能自己更新了**，以及**工作流补上了「提 MR」这一环**。

## 自动更新（本版最重要）

以前每次发版都要手动打包、手动发文件。现在：

- **应用自己检查更新**。启动时查一次，之后每 6 小时复查；发现新版本弹窗，
  显示版本号、发布日期与更新说明。
- **一键下载安装**。弹窗里点「下载并安装」，带实时进度条，装完自动重启。
- **设置 › 关于** 新增一页：当前版本、检查更新按钮、安装入口，以及仓库 / 更新日志 /
  问题反馈三个链接。
- **检查失败静默**。断网、GitHub 挂了都不会打扰你 —— 更新是锦上添花，不是必需能力。
  只有你在「关于」页主动点检查时才报错。

### ⚠️ 这一条要看完

**从 0.4.0 或更早版本升级的，收不到这次提示**（那些版本里还没有 updater 代码）。
需要手动装一次 0.5.0；装完之后，0.5.0 → 0.6.0 及以后就能自动更新了。

同理，自动更新依赖签名校验：包未签名或签名对不上时请求会被拒。

## 工作流：补上「提 MR」

- **新节点「提 MR」**：目标分支 + 可选标题，流程走到这里直接打开预填好的新建 MR 页。
  完整链路终于能串起来：`建分支 → 提交推送 → 提 MR → 切回起始分支`。
  
  注意它是**打开预填页**而不是创建 MR——平台创建 MR 需要 API token 授权，
  而本应用只用系统 git 凭据。最后那下 Create 仍由你点。

- **新节点「检出远程分支」**：与普通「切换分支」的区别是**保证拿到远程那份**。
  `git checkout feat/x` 在本地已有同名分支时只切换、不更新，容易误以为是最新的。
  这个节点会：先 fetch → 本地没有则建跟踪分支 → 落后则快进 → 有本地新提交则只切换
  （不丢东西，并在备注里说清「未与远程同步」）。

- **「删除分支不存在时跳过」不再是配置项**，改成默认行为。一个「有就删」的清理动作，
  没有「不存在就报错」的合理场景。描述里会写明这一点。

## 分组：可以藏起来了

- **分组支持在标签栏隐藏**。分组管理左栏每行一个眼睛图标；隐藏只影响标签栏那个文件夹，
  分组本身、组内仓库、总览和下拉里的可见性都不变。隐藏着的分组图标常驻，
  因为那正是恢复入口。

  一个细节：隐藏两个相邻分组后再拖动标签栏，恢复回来后位置不会乱 ——
  `barOrder` 里保留隐藏项、只在渲染时过滤，而不是从数据里删掉再猜着补回。

## 关于工作树

这一版**只**做了身份标识（标签栏区分主工作树 / 从属工作树）。
新建 / 删除工作树还没做，设计见 `docs/DESIGN-WORKTREE.md`。

## 安装

### 方式一：安装包（推荐）

```
git-zen_0.5.0_x64-setup.exe   4.3 MB
SHA256 7c2de84e8a497c6569733216f00a2da78e95f7185f53b81b49d5292fde672a89
```

### 方式二：免安装单文件

```
git-zen.exe   18 MB
SHA256 13a0a85f7502abf29a916e8258f15bd5ac395b0fa74e3f775bd5cc4bdcbca15b
```

安装包未签名，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。

依赖系统 WebView2 运行时（Win11 自带；Win10 一般已随 Edge 安装）。
